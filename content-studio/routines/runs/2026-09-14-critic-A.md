## Check 6 — LinkedIn format reality check (2026, applies to both)

- **GIF animation.** Uploaded via LinkedIn's native photo/image uploader (not the video uploader), GIFs **do animate** in the feed. Multiple 2026 sources agree on the upload-path requirement but **disagree on the exact size ceiling**: one source states a firm **5 MB** cap for the GIF to still animate ([authoredup.com](https://authoredup.com/blog/how-to-post-a-gif-to-linkedin)); another declines to give a hard number, calling behavior "inconsistent... can still differ between the desktop site, the mobile app, and which app version someone is running," and just recommends staying "well under the platform's image ceiling" ([2pr.io](https://2pr.io/blog/can-you-do-gifs-on-linkedin)). The kit's own README uses **~7.8 MB** as its working threshold. No authoritative single number found. Doesn't matter here: both shipped GIFs (1.81 MB / 2.02 MB) sit comfortably under all three cited figures. Uploading through a third-party scheduler risks LinkedIn flattening the GIF to a static frame — attach natively.
- **Image size limits.** Recommended dimensions for feed posts: 1200×627 (1.91:1 landscape) or 1080×1350 (4:5 portrait) for more feed real estate; minimum width 400px. A 3 MB cap is documented for LinkedIn **Page** images specifically; I could not independently confirm that exact cap applies identically to a personal-profile feed-post image (flagging the uncertainty rather than asserting it). Irrelevant either way: both poster PNGs (0.75–0.96 MB) are well under any cited number.
- **Document/PDF carousel.** Native organic "carousel" posts were retired **December 2023**; today's equivalent is a **document post** — upload a PDF/PPT/PPTX/DOC/DOCX (up to **100 MB, 300 pages** per LinkedIn's own Documents API docs, reconfirmed June 2026) and LinkedIn auto-paginates it into a swipeable card deck. As of a May 2026 benchmark refresh, document posts lead all LinkedIn content types at **6.6% average engagement** — but that number is earned by the *swipe* interaction on a multi-page deck. Both `poster.pdf` exports here are **single-page**, so posting them as a "document post" gets none of the swipe benefit and functionally behaves like a static image with an extra click to open.
- **Recommendation: default to the GIF.** It animates reliably at this file size on native upload, motion is what actually communicates "this is an interactive thing" to a scroller, and the mandatory amber honesty strip is baked into every frame — so the "rudimentary version, real one is at [url]" framing survives even if someone screenshots or reposts just the image. Use the PNG poster (1080×1080 square, or 1200×1500 portrait for more feed height) as the documented fallback for schedulers that are known to flatten GIFs, or for a reader who explicitly wants a still. Don't position the single-page PDF as a "document/carousel" post — keep it available as a downloadable, printable reference only; it isn't the multi-page format the 6.6%-engagement number is actually measuring.

Sources: [authoredup.com — how to post a GIF on LinkedIn](https://authoredup.com/blog/how-to-post-a-gif-to-linkedin) · [2pr.io — can you do GIFs on LinkedIn](https://2pr.io/blog/can-you-do-gifs-on-linkedin) · [connectsafely.ai — LinkedIn document posts/PDF guide 2026](https://connectsafely.ai/articles/linkedin-document-posts-pdf-guide-2026) · [sendible.com — LinkedIn post size 2026](https://www.sendible.com/insights/linkedin-post-size) · kit `content-studio/viz/kit/README.md` (own ~7.8 MB working threshold).
