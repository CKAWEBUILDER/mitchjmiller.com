# Visual Asset Provenance

This site should not use random image-search results, unlicensed stock photography, or client/private data screenshots.

## Rules

- Use owned assets, generated/vector assets, redacted screenshots, or public-page screenshots used as factual proof context.
- Keep source URLs or source working files for every proof asset.
- Label representative mockups as representative; do not imply they are live client dashboards or confidential systems.
- Do not add people/stock photography unless the license file or purchase record is stored with the asset notes.
- Do not publish private account data, client analytics, applicant data, donor data, veteran data, patient data, or screenshots from authenticated tools without redaction and approval.
- Keep `noindex` until final content, legal, and source QA are complete.
